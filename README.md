# 1. Побудова FlameGraph виконання

## 1.1. Демонстрація процесу побудови
Для візуалізації розподілу часу виконання процесора та виявлення вузьких місць у програмі множення матриць без оптимізації (`-O0`) було виконано такі кроки:

- **Компіляція з відлагоджувальними символами:**
  Код програми було скомпільовано з прапорцем `-O0` (вимкнена оптимізація) та прапорцем `-g` для збереження символів функцій:
  ```bash
  g++ -O0 -g matrix_mult.cpp -o matrix_00
- **Збір профілюючих даних за допомогою perf**
  За допомогою системного профілювальника виконано запис стека викликів програми з частотою семплування 99 Гц:
  ```bash
  sudo perf record -F 99 -g -- ./matrix_О0
- **Згортання стека викликів:**
  Сирі дані за допомогою скрипта перетворено у згорнутий формат:
  ```bash
  sudo perf script > out.perf
  ~/FlameGraph/stackcollapse-perf.pl out.perf > folded.perf
- **Генерація фінального графіка (SVG):**
 Створено векторний інтерактивний графік flamegraph_00.svg:
  ```bash
  ~/FlameGraph/flamegraph.pl folded.perf > flamegraph_O0.svg
